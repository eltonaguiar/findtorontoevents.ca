## Quick Start

```bash
# Install dependencies
pip install -r requirements.txt

# Initialize database and run a demo scan
python run_miracle.py demo

# Run the Adaptive Oracle demo (simulated trades + learning)
python run_miracle.py demo-oracle

# Full universe scan
python run_miracle.py scan --strategy "Miracle Momentum Burst" --top 10

# Scan with Oracle's learned weights
python run_miracle.py scan-oracle --top 5

# Show Questrade CDR fee savings
python run_miracle.py fees

# List strategies and portfolios
python run_miracle.py strategies
python run_miracle.py portfolios
```

## The Adaptive Oracle

The sister algorithm that **learns from every trade**:

- **Wins** reinforce the scoring components that predicted correctly
- **Losses** penalize components that gave false signals
- **Blacklists** tickers where the Oracle consistently fails
- **Regime-aware**: learns cautiously in volatile markets
- **Fully auditable**: every weight change is logged with epoch snapshots
